# Agentic TRICODE PRO

This is the new autonomous technical execution operating system.

## Project Structure
- `agentic-pro-app/`: The Next.js 14 frontend using the 4-panel Agentic UX shell.
- `backend/`: FastAPI backend for agent orchestration and real-time WebSocket pulses.
- `lib/`: Shared utilities and MCP (Model Context Protocol) connectors.

## Getting Started
1. Install dependencies: `npm install` (in agentic-pro-app)
2. Run development server: `npm run dev`
3. Start the Brain: `python backend/main.py`

## Features
- **4-Panel Operational Shell:** Icon Bar, Context Sidebar, Main Canvas, and Intelligence Panel.
- **AI-Native Interactions:** Status pulses, automated sprint prediction, and multi-agent coordination.
- **MCP Integration:** Tool-access layer for GitHub, Slack, and internal data.
